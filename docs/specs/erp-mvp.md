# ERP MVP：进销存（产品 / 库存 / 采购 / 销售 / 财务 / 首页统计）

## Problem Statement

平台底座（system/infra/bpm/消息/套餐）与 CRM、OA 两个业务套件已交付，但项目对标的芋道套件清单里还差进销存：作为单人全职的长期能力对标项目，下一个里程碑需要 ERP——产品与库存账、采购与销售单据链路、结算账户与收付款核销。没有 ERP，mall/pay 等后续套件也没有可参照的单据与库存先例。

## Solution

一次交付全量对标芋道 ERP 的六大块：产品管理（分类/单位/产品）、库存管理（仓库/库存/流水/其它出入库/调拨/盘点）、采购管理（供应商/订单/入库/退货）、销售管理（客户/订单/出库/退货）、财务管理（结算账户/收款单/付款单）、ERP 首页统计。施工顺序：骨架+主数据 → 库存核心 → 采购三单 → 销售三单 → 调拨盘点 → 财务 → 统计报表 → Excel/演示/验收。

## User Stories

1. 作为仓库管理员，我想要维护产品分类树、单位与产品（条码/规格/参考价），这样采购销售单据有统一货品主数据。
2. 作为仓库管理员，我想要产品被单据引用时禁止删除，这样不会产生悬空明细。
3. 作为仓库管理员，我想要维护仓库（含负责人展示字段），这样出入库有明确场所。
4. 作为仓库管理员，我想要看到仓库×产品的库存余额分页与产品全仓合计，这样随时知道有什么、在哪里。
5. 作为仓库管理员，我想要任何库存变动都留一条流水（正入负出、带结存快照与业务单号），这样余额可以由流水重放验证。
6. 作为仓库管理员，我想要出库导致负库存时直接 409（并发下同样成立），这样库存账永远可信。
7. 作为仓库管理员，我想要用其它入库/出库单处理赠品、报损等杂项收发，这样非订单业务也有账。
8. 作为仓库管理员，我想要用调拨单把货品在两个仓库间转移（一增一减同额），这样多仓库存不靠手工对账。
9. 作为仓库管理员，我想要用盘点单按实际清点数校准账面（盘盈入、盘亏出），这样账实一致。
10. 作为采购员，我想要维护供应商（税号/税率/开户信息，纯记录），这样采购单据有往来单位。
11. 作为采购员，我想要创建采购订单（明细行数量×单价、行金额联动合计），这样采购意向成单。
12. 作为采购员，我想要从已审核订单发起采购入库并审核入账，这样到货即增库存、订单进度自动回写。
13. 作为采购员，我想要入库数量受订单数量占用约束（未审核单也占用量），这样不会超采。
14. 作为采购员，我想要采购退货单挂已审核入库单、审核后减库存，这样退回供应商有账可查。
15. 作为采购主管，我想要已审核单据不可改删、错误走退货单更正，这样账目不可被悄悄改写。
16. 作为采购主管，我想要反审核用新增反向流水回滚（原流水保留、下游收付款存在时禁止），这样纠错可审计。
17. 作为销售员，我想要维护 ERP 客户（独立于 CRM 客户的主数据），这样销售单据有往来单位。
18. 作为销售员，我想要创建销售订单并从已审核订单发起销售出库，这样发货即减库存、进度回写。
19. 作为销售员，我想要销售退货单挂已审核出库单、审核后回库存，这样退回入库有账。
20. 作为财务，我想要维护结算账户并设唯一默认账户，这样收付款有明确资金账户。
21. 作为财务，我想要收款单明细只能挂已审核的销售出库/退货，且核销合计不超单据总额，这样不会多收多记。
22. 作为财务，我想要付款单镜像挂采购入库/退货并同样限额，这样付款可控。
23. 作为财务，我想要审核收付款后单据的已收/已付金额自动回写、反审核自动重算，这样核销状态始终准确。
24. 作为财务，我想要出库单存在已审核收款时禁止反审核，这样资金与物流不会脱钩。
25. 作为财务，我想要账户列表显示"余额=已审核收付款净额"的实时查询列（不落库），这样一眼看到各账户资金。
26. 作为租户管理员，我想要 ERP 首页统计：销售/采购的今日/昨日/本月/今年四值与近 N 月趋势（口径=已审核出入库−退货），这样经营盘子可视化。
27. 作为租户管理员，我想要 ERP 单据与主数据的可见性按角色数据范围上限 + 创建人（owner）过滤，这样沿用全项目统一的数据权限。
28. 作为租户管理员，我想要 ERP 菜单与按钮权限由种子下发、普通角色默认不授予，这样新租户开箱即用且财务敏感页可控。
29. 作为租户管理员，我想要客户/供应商/仓库/结算账户被单据引用时禁止删除，这样统计与核销不会被悬空引用污染。
30. 作为财务，我想要十二类单据统一编号（2 字母前缀+日期+租户内序号，客户端伪造不采纳），这样单号可读唯一。
31. 作为开发者，我想要数量用毫单位定点类型（ADR 0017）、金额沿用 Money（ADR 0007），这样库存账全程无浮点误差。
32. 作为开发者，我想要所有库存变动只走唯一入账入口（校验→更新余额→插流水，SQL 双保险），这样不变量只在一处维护。
33. 作为开发者，我想要 ERP 模块不依赖 crm/oa/bpm、主数据独立建表（ADR 0015），这样两域可独立演进。
34. 作为开发者，我想要 HTTP 契约集成测试覆盖负库存/并发扣减/反审核回滚/核销上限/删除约束/编号/统计口径/租户隔离，这样高风险路径有回归保护。
35. 作为开发者，我想要产品/库存/单据列表提供 Excel 导出（沿用 CRM Excel 约束），这样离线整理与对账方便。
36. 作为运维，我想要空库迁移往返校验 EXPECTED_TABLES=100、迁移按域拆分带 Down 段，这样升级可审计可回滚。
37. 作为演示者，我想要 make run-demo 一键重建完整业务链路演示数据（采购入库→销售出库→收付款→统计可见），这样向他人演示不用手工造数。

## 实现与测试

- 新增 `internal/module/erp`（api/dto/model/repository/service 五层），表 34 张（主数据 6、库存 2、采购 6、销售 6、杂项 8、财务 5、序列 1），`EXPECTED_TABLES` 66→100；迁移 00029 起按域拆 6 个；菜单 seed 700 段（按钮=菜单ID×10+n），普通角色默认不授 ERP。
- 状态机（10/20 审核语义、反审核反向流水与禁令）、库存唯一入账入口与负库存双保险、占用与进度回写、核销上限与回写、编号前缀、删除约束、数据权限、API 清单、前端页面、测试矩阵，以 [`docs/erp-mvp-spec.md`](../erp-mvp-spec.md) 为唯一来源；本文件不复制规则正文。
- 架构取舍见 ADR 0015（域边界）、0016（纯数量账+反审核）、0017（数量定点）。

## Out of Scope

- 成本核算/移动加权/毛利（ADR 0016 拒绝，backlog）；批次/序列号；多单位换算；多币种；税额计算。
- bpm 审批接入 ERP 单据；CRM↔ERP 打通（合同→销售订单、主数据归一）。
- 排行报表、移动端、应收应付账龄、总账/凭证/发票、Excel 导入。
- 仓库独立权限；mall 打通（bar_code 仅预留字段）。
- 芋道 API/DDL/前端 drop-in 兼容（契约 C1）。

## Further Notes
